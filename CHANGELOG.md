# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-04-01

### Added
- **@claws-shield/core** — Shared types, scoring engine, knowledge base loader
- **@claws-shield/intel** — Intelligence query engine with 250+ feature flags, model codenames, and version diffs
- **@claws-shield/scanner** — Security scanning engine with 15+ rules across 6 categories
- **@claws-shield/auditor** — Flagship audit engine with 7 analyzers (telemetry, remote control, undercover, permissions, network, hidden tools, privacy)
- **@claws-shield/gateway** — Multi-model routing proxy (Anthropic, OpenAI, Gemini, Ollama)
- **@claws-shield/cli** — Standalone CLI with audit, scan, intel, and gateway commands
- 4 OpenClaw skills for ClawHub distribution
- Knowledge base with research data from Claude Code v2.1.88 analysis
- Bilingual documentation (EN/CN)
- CI/CD with GitHub Actions
